What is A2A?

The basic objects and transports in the Agent2Agent protocol.

The Agent2Agent (A2A) protocol gives independently built agents a shared way to discover capabilities, exchange messages, and manage work. A2A documentation

The core objects

An Agent Card is published at `/.well-known/agent-card.json`. It describes an agent's skills and interfaces so another agent can discover it. AWS AgentCore A2A guide

Tasks represent units of work. Messages carry Parts, including text, raw data, URLs, and media. A2A v1.0 changes

Transports and v1.0

A2A supports JSON-RPC, gRPC, and REST transports. Version 1.0 added verb-style operations, a unified Part model, `supportedInterfaces`, signed Agent Cards, device-code OAuth, and cursor pagination. A2A v1.0 changes

A2A and MCP

MCP is for an agent’s connection to tools and data; A2A is for agent discovery, delegation, and collaboration. They are complementary protocols. AAIF ecosystem overview
