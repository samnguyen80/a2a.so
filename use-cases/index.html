A2A use cases

Documented patterns for using an agent-to-agent protocol.

The examples below are patterns documented by public sources. They are not claims about named customer outcomes.

Hosted A2A servers

Deploy an A2A server on AWS AgentCore Runtime, with OAuth or SigV4 authentication. AWS documentation

Copilot Studio connections

Use a Copilot Studio agent to call external, third-party agents. Microsoft announcement

Specialist delegation

An orchestrator can delegate to specialists built with different frameworks, such as a LangGraph orchestrator working with ADK or CrewAI agents. Semantic Kernel example

Commerce and payments

The Linux Foundation describes AP2 and A2A work as part of agentic commerce and payments. Linux Foundation release

Test and inspect agents

Use A2A Inspector and the A2A Technology Compatibility Kit for inspection and validation.

Multi-agent samples

Public samples include a travel assistant and a slide-generation project that combine A2A with other agent tooling. GitHub repository search

Framework scaffolding

The AgentCore CLI documents A2A scaffolding with Strands, LangChain/LangGraph, and Google ADK. AWS documentation
