# Live A2A ecosystem stats

These values are refreshed by a scheduled build from the GitHub, PyPI, and npm APIs. On an API error, the prior recorded value remains visible.

## What is measured

- Core repository stars and latest release: [GitHub releases](https://api.github.com/repos/a2aproject/A2A/releases)
- Python SDK downloads: [PyPIStats](https://pypistats.org/api/packages/a2a-sdk/recent)
- JavaScript SDK downloads: [npm downloads API](https://api.npmjs.org/downloads/point/last-week/@a2a-js/sdk)
- Community repository count: [GitHub repository search](https://api.github.com/search/repositories?q=a2a+agent2agent+in:name,description,topics)
