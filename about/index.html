About a2a.so

Why this independent, source-linked A2A reference exists.

a2a.so is an independent community resource for developers, product teams, and agents evaluating the Agent2Agent protocol. It aims to make primary documentation, ecosystem signals, and useful repositories easier to find.

Editorial approach

We keep claims short, link them to public sources, distinguish announced support from documented deployments, and retain prior live measurements if a source API is unavailable.

Ownership and contact
