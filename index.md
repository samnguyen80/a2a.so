# A practical guide to Agent2Agent

A2A is an open protocol for agents to discover one another, delegate work, and collaborate across systems. [Official documentation](https://a2a-protocol.org/)

## A protocol for agent-to-agent work

It complements MCP: MCP connects agents to tools and data, while A2A connects agents to other agents. [AAIF ecosystem overview](https://aaif.io/blog/where-a2a-fits-in-the-open-agent-ecosystem)
